Statement## Repo shape — npm workspaces monorepo Two workspaces (`package.json` `workspaces`): - **`@singedterra/client`** (`client/`) — Vite/Canvas 2D app: renderer, input, UI, audio, `NetworkClient`. Statement## Testing Verification layers have distinct scopes; a pass in one is not acceptance for another: - **Engine / pure helpers** — deterministic harnesses in `scripts/checks/*.mjs`, run via `tsx` (`npm run check`), asserting byte-identical replay of `(seed + ordered action log)`. Cover the `shared/` engine and the pure client helpers (browseLabels, inputGate, ringBuffer, fastForward, strata, audioEdges, …). - **Edge Functions** — Deno `*.test.ts` (`npm run check:edge` → `deno test --allow-env`), covering the pure referee logic (validate/authorize/coerce/reap) extracted from the handlers. - **Client (DOM + fetch)** — **Vitest** `5.0.5` with the **jsdom** environment (`npm run test:client`), giving the DOM- and `fetch`-heavy client code (Lobby, HUD, NetworkClient) a seam the tsx harnesses cannot reach. **Coverage:** `@vitest/coverage-v8` `5.0.5` via `npm run coverage:client` — this is the command the `/ca:refactor` Phase-2 gate reads. Added 2026-07-03 to unblock the client refactor backlog (#85/#87/#91); vitest/vite/esbuild are dev-only (not in the shipped bundle). Coverage uses AST-aware v8 remapping, so percentages are not directly comparable to Vitest 2 reports; the executable test set remains the governing compatibility oracle until a global threshold is adopted. - CI runs engine, Edge and client layers (`.github/workflows/ci.yml`). Last Stand also has pure C# harnesses launched through Python, imported Unity checks, rendered browser journeys, native player builds and physical-device observations. Current suite selection is maintained separately from historical receipts; not every historical tool is a portable CI test. - The existing stage-1 client policy keeps a 60% floor over the assertable-logic denominator in `client/vite.config.ts`. V8 reports lines and branches; production exclusions are unchanged. The Windows baseline at af17d905 measured 94.91% lines and 84.79% branches with 2,405 passing tests. This is one source/host observation, not a new global coverage policy or a result for later changes. Shared engine, Edge and C#/Python numeric coverage remain unmeasured by that client command. The repository does not currently declare numeric coverage commands for those separate trees.
